# MX-Core AI Fitness App

MX-Core is an AI-based fitness and gym management application developed as a collaborative team project. The application is designed to manage gym-related activities and provide a smart and user-friendly experience.

## Features

* User management
* Gym admission and member handling
* AI-based fitness-related functionalities
* Backend server integration
* Database connectivity

## Technologies Used

### Frontend

* EJS

### Backend

* Node.js

### Database

* MongoDB

### Runtime Environment

* Node.js

## Project Type

Collaborative Team Project

* Enhanced UI/UX
* Authentication and security improvements
* Advanced AI-based recommendations
* Deployment and cloud integration
